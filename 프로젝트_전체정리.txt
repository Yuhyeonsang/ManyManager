[ 프로젝트 개요 ]
--------------------------------------------------------------------------------
한국 주식 시장의 종목 데이터를 수집/분석하고, 갤럭시 S24의 React Native 앱에서
조회 가능한 AI 기반 펀드매니저 시스템.

핵심 아키텍처:
  - 백엔드: FastAPI(Python) + Oracle Cloud Free Tier 무중단 서버
  - AI: Gemini 1.5 Flash (뉴스 필터링, 관련주 추론)
  - 시맨틱 레이어: 모든 숫자 계산은 파이썬, AI는 의미 해석만 (환각 방지)
  - DB: SQLite (핸드폰 내 로컬 + 서버 누적 통계)
  - 자동 배포: GitHub Actions (push 시 SSH로 서버 업데이트, Expo OTA)

▶ 발생한 문제와 해결:

  [문제 1] .bat 파일 한글 깨짐

           react-native 0.81.4 등)

  [문제 3] react-native-gesture-handler 누락
    원인: React Navigation v7 native-stack의 peer dependency 누락
    해결: package.json에 "react-native-gesture-handler": "~2.28.0" 추가

     - reports                     : 시간별 종목 리포트 메타+요약

     a) today_total() 호출 -> DAILY_BUDGET_USD 초과 시 break
     b) 신규 뉴스 hash 비교 -> 중복은 건너뜀
     c) 신규만 Gemini 호출
     d) 호출 후 사용 토큰 -> api_usage에 기록

  3. 안전 종료:
     - SIGINT (Ctrl+C) / SIGTERM -> finally 블록에서 DB connection 정리

▶ 환경변수:

================================================================================

▶ "python을 인식할 수 없습니다"
  -> Python 설치 시 "Add python.exe to PATH" 체크 안 함
  -> 재설치 또는 환경변수 PATH에 추가:
     C:\Users\<사용자>\AppData\Local\Programs\Python\Python312\

▶ "Network Error" (모바일 앱)
  1. PC와 핸드폰이 같은 와이파이 연결 (5G 모바일 데이터면 안 됨)
  2. fund-manager-app/src/services/api.js의 BASE_URL이 PC IP와 일치
  3. Windows 방화벽 uvicorn 차단 -> 첫 실행 팝업에서 "허용"
  4. 회사/기숙사 와이파이는 기기 간 통신 차단 -> 핸드폰 핫스팟 사용

▶ "missing GEMINI_API_KEY" / "missing dart api key"
  -> .env 파일이 없거나 키가 비어있음. .env.example 보고 채워넣기

▶ "Project is incompatible with this version of Expo Go"
  -> 핸드폰 Expo Go가 최신(SDK 54)인데 프로젝트가 이전 버전
  -> fix_app.bat 더블클릭 (전체 재설치) 또는 quick_fix.bat (빠진 패키지만)

▶ ImportError: cannot import name 'collect_news'
  -> data_collector.py 끝에 collect_news() 함수 추가됨 (해결 완료)
